## 🛠️ Технологический стек

### Backend:
- **Supabase** - PostgreSQL database + Auth + Realtime
- **Row Level Security (RLS)** - Защита данных

### Frontend:
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Leaflet** (карты)

### Будущие интеграции:
- **Solana Wallet Adapter** - для кошелька
- **React Query / SWR** - для кеширования (опционально)
- **Zustand** - для state management (опционально)

---

## 🔐 Безопасность

### Реализовано в схеме БД:
- ✅ Row Level Security (RLS)
- ✅ Политики доступа для всех таблиц
- ✅ VIP контент защищен
- ✅ Пользователи могут редактировать только свой профиль

### Требует внимания при интеграции:
- ⚠️ Валидация на клиенте и сервере
- ⚠️ Проверка VIP статуса для защищенных функций
- ⚠️ Безопасное хранение токенов
